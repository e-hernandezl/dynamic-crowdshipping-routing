# **Dynamic Crowdshipping Routing**

Research project focused on the optimization of Dynamic Vehicle Routing Problems (DVRP) with opportunistic requests through crowdshipping mechanisms.

### ***Research Areas***

- Vehicle Routing Problem (VRP)
- Dynamic Vehicle Routing Problem (DVRP)
- Crowdshipping
- Last-Mile Logistics
- Operations Research
- Metaheuristics
- Geospatial Data Analysis

### ***Institution***

Centro de Investigación en Computación (CIC-IPN)

### ***Research Laboratories***

- Intelligent Geospatial Information Processing Laboratory
- Networks and Data Science Laboratory

### ***Research Objective***

Develop optimization models and solution approaches for integrating crowdshipping resources into dynamic last-mile delivery systems.

Dynamic Vehicle Routing Problem (DVRP) · Last-Mile Delivery · Crowdshipping · Opportunistic Requests · Metaheuristics · Combinatorial Optimization
